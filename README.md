# Document Studio

**Document Studio** is a free, open-source desktop application for Windows and Linux that combines document editing, educational tools, PDF conversion, and creative design capabilities in one place.

Create and format documents, import PDFs and scanned pages, prepare and mark educational assignments, and design everything from technical drawings to medical, mathematical, and scientific diagrams.

## Features

- **Document Editing:** Create and format documents with tables, equations, citations, page layouts, and templates.
- **Teacher Tools:** Easily create, manage, and mark assignments using dedicated educational tools.
- **PDF & Image Import:** Convert PDFs and scanned documents into editable content with built-in OCR.
- **2D & 3D Design:** Create diagrams, technical drawings, and visual representations using dedicated design workspaces.
- **Scientific & Specialized Diagrams:** Create medical, mathematical, geological, architectural, and other scientific diagrams.
- **Document Export:** Save your work as editable projects or export to DOCX, ODT, and PDF.
- **Offline Functionality:** Includes the necessary OCR models, dictionaries, fonts, and document-processing resources.
- **Customizable Appearance:** Choose between Light, Dark, and Purple themes.
- **Printing:** Print documents directly from the application.
- **Built-in Updater:** Manually check for, download, and install new updates directly from the application.

## Download & Installation

Document Studio is available for **Windows and Linux**.

| Platform | Available Format |
|---|---|
| Windows (x64) | EXE Installer |
| Fedora / RPM-based Linux | RPM Package |
| Debian / Ubuntu-based Linux | DEB Package |
| Other compatible Linux distributions | TAR.GZ Installer |

Download the latest available version from the **[GitHub Releases](../../releases)** page.

*Note: Linux builds require glibc 2.39 or newer, GTK 3, and WebKitGTK 4.1.*
